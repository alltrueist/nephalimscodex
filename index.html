📜 How to Use Nephalem's Codex

  1. Set your Build Name and Class — filters all items and aspects to your class
  2. Click any Gear Slot to add items from your build guide:
    — Quick Pick filters items to your class • Uniques auto-fill boss sources • Legendaries take aspect + affixes + tempers + MW priority
  3. The 📋 Acquisition Guide tab shows boss farm targets, Cube recipes, aspects, and step-by-step crafting plans
  4. The 🟫 Crafting Simulator tab walks you through the optimal Horadric Cube rolling order for any set of 4 affixes — including when to use the Enchanter to lock stats
  5. From any Legendary slot, hit 🟫 Plan This Craft to jump straight to the simulator pre-filled
💾 Auto-saves in your browser.  🔄 Aspects DB auto-updates weekly via GitHub Actions.
