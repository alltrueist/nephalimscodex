### Diablo 4 Build Gear Acquisition Planner

---

## What Is This?

Build guides tell you *what* gear to use — but they never tell you *how to get it*. Nephalem's Codex fills that gap.

Enter your gear list from any build guide (Maxroll, Mobalytics, D4Builds) and instantly get:

- 💀 **Boss Farm Targets** — Which Lair Boss to run, what key material you need, and where to farm the key
- ⚜️ **Mythic Unique Targets** — Belial farming chain clearly explained
- 🟫 **Horadric Cube Crafting** — Exactly which recipes to use (3-to-1, Add Affix, Focus Reroll, Transfigure)
- 📖 **Aspects to Collect** — Drop-sourced aspects clearly called out (no more dungeon confusion)
- 🔨 **Legendary Gear Build Steps** — Base → Cube → Aspect → Temper → Masterwork, per piece
- 📚 **Cube Quick Reference** — All recipes and Tuning Prisms always visible at the bottom

**Auto-saves your build in the browser** — still there the next time you visit.

## How to Use

1. Open a build guide on **Maxroll, Mobalytics, or D4Builds**
2. Set your **Build Name** and **Class** — this filters all item lists to your class
3. Click any **Gear Slot** on the left to open the editor:
   - **Quick Pick** — browse items for that slot filtered to your class; click to select
   - **Uniques / Mythics** — just type or click the name; boss source auto-fills in the guide
   - **Legendaries** — fill in the aspect, affixes, tempers, and masterwork priority
4. Your **Acquisition Guide** updates live on the right
5. Hit **📋 Copy** to export a plain-text checklist

## Data Pipeline — Keeping Aspects Up to Date

The legendary aspects database is auto-generated by a GitHub Actions workflow that scrapes **d4guides.gg** (495 aspects, updated every patch).

### Run manually (locally)

```bash
pip install -r requirements.txt
python scripts/fetch-data.py
```

This writes fresh `data/aspects-db.js` and `data/aspects-raw.json` files. Commit and push to update the live site.

### Automatic weekly updates (GitHub Actions)

The workflow `.github/workflows/fetch-data.yml` runs every Monday at 6 AM UTC automatically. It:
1. Fetches all aspects from d4guides.gg
2. Writes `data/aspects-db.js`
3. Commits the updated file directly to `main`
4. GitHub Pages serves the new data within ~60 seconds

**To trigger manually:**
> GitHub repo → **Actions** tab → **Fetch D4 Game Data** → **Run workflow**

## Expanding the Database Manually

### Add a Unique Item (`data/items-db.js`)

Find the correct boss section and add one line:

```javascript
u("my-item-id", "Item Name", "slot", "Slot Display", "Class", "unique", [b(BOSS_ID)]),
```

Boss ID aliases: `AN`=Andariel · `AS`=Astaroth · `BA`=Bartuc · `BI`=Beast in Ice  
`BL`=Belial · `BU`=Butcher · `DU`=Duriel · `GR`=Grigoire  
`HA`=Harbinger · `LZ`=Lord Zir · `UR`=Urivar · `VA`=Varshan

Slot IDs: `helm` `chest` `gloves` `pants` `boots` `amulet` `ring` `weapon` `offhand`

### Add an Aspect (`data/aspects-db.js`)

Add one line to the `D4DB.aspects` array:

```javascript
{ id:"my-aspect",name:"Aspect Name",class:"Rogue",
  slots:["gloves","offhand","weapon","ring","amulet"],codex:false,
  effect:"Effect text here.",source:"Salvage Legendary drops" },
```
